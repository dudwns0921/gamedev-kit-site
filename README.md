# gamedev-kit-site

The landing page of [claude-gamedev-kit](https://github.com/dudwns0921/claude-gamedev-kit): what the kit is, how to install it, and how to use it. One static page (Next.js), deployed on Vercel.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build
```

The usage it shows follows the kit's README — when the kit's commands or install lines change, change `app/page.tsx` with them.
The pictures in `public/` are the kit's own (`assets/` in the kit repository).
